# Публикация релиза на GitHub

## Зачем нужен релиз

Приложение умеет проверять обновления через GitHub. Чтобы проверка была полезной, нужно публиковать версии в репозитории.

Репозиторий:

```text
Pacifica123/it_cost_mobile
```

## Как сделать релиз

1. Собрать APK.
2. Открыть GitHub-репозиторий.
3. Перейти в **Releases**.
4. Нажать **Draft a new release**.
5. Создать тег, например:

```text
v1.0.1
```

6. Назвать релиз:

```text
IT Cost Mobile v1.0.1
```

7. Прикрепить APK-файл.
8. В описание добавить изменения.
9. Опубликовать релиз.

## Пример описания релиза

```text
Изменения:
- упрощено Меню ИТ;
- улучшена тёмная тема;
- добавлены инструкции;
- исправлены цвета текста;
- обновлена проверка обновлений.

Перед установкой:
- при необходимости экспортируйте проект;
- после обновления проверьте настройки темы и валюты.
```

## Что проверяет приложение

Экран обновлений может:

- прочитать последний GitHub Release;
- сравнить версию;
- открыть страницу релиза;
- открыть прикреплённый файл, если он есть.

## Важно

Если релиз не создан, приложение может fallback-режимом читать `app.json`, но нормальный способ обновлений — именно GitHub Releases.
