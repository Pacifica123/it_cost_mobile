# Чек-лист релиза

## Перед сборкой

- [ ] Обновить версию приложения.
- [ ] Проверить `app.json`.
- [ ] Проверить `eas.json`.
- [ ] Запустить `npm install`.
- [ ] Запустить `npm run check`.
- [ ] Проверить светлую тему.
- [ ] Проверить тёмную тему.
- [ ] Проверить компактный/обычный/крупный режим.
- [ ] Проверить загрузку примера.
- [ ] Проверить, что отчёт не показывает нули после загрузки примера.
- [ ] Проверить импорт CSV.
- [ ] Проверить экспорт JSON.
- [ ] Проверить HTML/Markdown отчёт.
- [ ] Проверить кнопку домой.
- [ ] Проверить экран обновлений.

## Сборка APK

```powershell
$env:EAS_NO_VCS="1"
eas build -p android --profile preview
```

## После сборки

- [ ] Скачать APK.
- [ ] Установить APK на устройство.
- [ ] Проверить запуск после чистой установки.
- [ ] Проверить запуск после обновления старой версии.
- [ ] Проверить локальные данные.
- [ ] Создать GitHub Release.
- [ ] Прикрепить APK к релизу.
- [ ] Проверить, что экран обновлений видит релиз.

## Минимальный ручной тест

1. Открыть приложение.
2. Загрузить пример.
3. Открыть Меню ИТ.
4. Открыть Расчёты.
5. Открыть Аналитику.
6. Открыть Отчёт.
7. Переключить тему.
8. Переключить размер интерфейса.
9. Проверить обновления.
