# Руководство пользователя

## 1. Главная

Главная показывает вход в приложение и быстрый доступ к сервисным функциям:

- **Меню ИТ** — основной рабочий раздел.
- **Настройки** — тема, валюта, размер интерфейса, отчёт, CSV, обновления.
- **Диагностика** — состояние данных и хранилища.
- **Обновления** — проверка новой версии на GitHub.

## 2. Меню ИТ

Меню ИТ построено вокруг сценария:

1. **Проект** — описание и управление проектом.
2. **Расчёты** — ввод затрат и инфраструктуры.
3. **Аналитика** — проверка результатов.
4. **Отчёт** — итоговая выгрузка.

Кнопка **Продолжить** подсказывает следующий полезный шаг.

## 3. Проект

В разделе **Проект** находятся:

- паспорт проекта;
- список сохранённых проектов;
- импорт и экспорт;
- резервные копии;
- шаблоны;
- очистка проекта.

Очистка проекта — опасное действие. Перед ней желательно создать резервную копию.

## 4. Расчёты

В разделе **Расчёты** находятся основные исходные данные:

- **Техническое оборудование** — компьютеры, серверы, сеть, периферия.
- **Программное обеспечение** — ОС, офисные пакеты, антивирусы, спец. ПО.
- **CAPEX** — разовые затраты.
- **OPEX** — ежемесячные/периодические затраты.
- **Электроэнергия** — потребление и стоимость энергии.
- **Каталог** — типовые позиции.
- **Конструктор комплекта** — быстрый подбор комплекта.
- **Автоподбор** — подбор варианта под бюджет.

## 5. Аналитика

В разделе **Аналитика** можно оценить проект:

- сводка и графики;
- риски и рекомендации;
- сценарии;
- локально vs облако;
- амортизация;
- NPV;
- AHP;
- генетический подбор;
- сравнение методов.

Для обычной проверки чаще всего достаточно открыть **Сводку**, **Риски** и **Сравнение методов**.

## 6. Отчёт

Раздел **Отчёт** предназначен для итоговой выгрузки:

- проверка готовности;
- итоговый отчёт;
- история изменений.

Перед финальной выгрузкой желательно закрыть предупреждения в проверке готовности.

## 7. Настройки

Основные настройки:

- тема: системная, светлая, тёмная;
- размер интерфейса: компактный, обычный, крупный;
- стартовый экран;
- валюта и курсы;
- горизонт расчёта;
- ставка дисконтирования;
- параметры отчёта;
- настройки CSV;
- автобэкап перед опасными действиями;
- проверка обновлений.

## 8. Импорт CSV

Поддерживаемые колонки:

| Русское название | Английское название | Описание |
|---|---|---|
| название | name | Наименование позиции |
| цена | price | Стоимость |
| количество | quantity | Количество |
| раздел | type | CAPEX, OPEX, ТО, ПО |
| категория | category | Категория позиции |

Перед импортом лучше включить предпросмотр CSV в настройках.

## 9. Резервные копии

Резервные копии нужны перед:

- очисткой проекта;
- импортом CSV;
- применением шаблонов;
- массовым удалением.

Если данные испортились, откройте **Проект → Резервные копии** и восстановите нужную копию.

## 10. Частый рабочий сценарий

1. Создать или открыть проект.
2. Указать бюджет и рабочие места.
3. Добавить позиции через конструктор или каталог.
4. Проверить CAPEX/OPEX.
5. Проверить риски.
6. Открыть аналитику.
7. Сформировать отчёт.
