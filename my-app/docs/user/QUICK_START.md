# Быстрый старт пользователя

## Для чего приложение

IT Cost Mobile помогает собрать и проверить расчёт IT-инфраструктуры: оборудование, программное обеспечение, разовые и ежемесячные затраты, электроэнергию, аналитику и итоговый отчёт.

## Самый простой путь

1. Откройте приложение.
2. На главной нажмите **Меню ИТ**.
3. В блоке **С чего начать** двигайтесь по порядку:
   - **Проект** — задайте название, бюджет и рабочие места.
   - **Расчёты** — заполните оборудование, ПО, CAPEX, OPEX и электроэнергию.
   - **Аналитика** — проверьте сводку, графики, риски и сценарии.
   - **Отчёт** — сформируйте итоговую выгрузку.
4. Если не хотите заполнять всё вручную, нажмите **Загрузить пример** или используйте **Конструктор комплекта**.

## Что значат главные разделы

| Раздел | Что внутри |
|---|---|
| Проект | Паспорт, мои проекты, импорт/экспорт, резервные копии |
| Расчёты | ТО, ПО, CAPEX, OPEX, электроэнергия, каталог, автоподбор |
| Аналитика | Сводка, графики, NPV, AHP, GA, риски, сценарии |
| Отчёт | Проверка готовности, итоговый отчёт, история |
| Сервис | Настройки, диагностика, обновления |

## Что делать новому пользователю

Лучше не начинать с NPV, AHP или GA. Сначала заполните базу:

1. Проект.
2. ТО и ПО.
3. CAPEX и OPEX.
4. Электроэнергия.
5. Аналитика.
6. Отчёт.

## Как понять, что расчёт готов

На экране **Меню ИТ** и в **Отчёте** есть показатели:

- **готовность** — насколько заполнены основные блоки;
- **качество данных** — насколько расчёт выглядит надёжным;
- **продолжить** — приложение подсказывает следующий шаг.

## Как сохранить результат

Используйте раздел **Отчёт**:

- Markdown — удобно копировать текст.
- HTML — удобно открыть в браузере.
- Печать / PDF — можно сохранить через системную печать в PDF.
