# Устранение проблем

## EAS пишет: Missing build profile "apk"

Используйте профиль `preview`:

```powershell
$env:EAS_NO_VCS="1"
eas build -p android --profile preview
```

Профиль `preview` уже собирает APK.

## EAS пишет: git command not found

Быстрый обход:

```powershell
$env:EAS_NO_VCS="1"
eas build -p android --profile preview
```

Нормальное решение — установить Git for Windows и открыть PowerShell заново.

## Изменения в интерфейсе не видны

Очистить кэш Expo:

```bash
npm run fresh
```

Если не помогло:

```bash
npx expo start -c
```

## Тёмная тема выглядит светлой

Проверить:

1. Настройки → тема.
2. Перезапустить экран.
3. Запустить свежую сборку.
4. Убедиться, что установлен архив с последними исправлениями.

Если компонент всё равно светлый, вероятно в нём остались жёстко заданные цвета.

## После загрузки примера отчёт показывает нули

Порядок проверки:

1. Нажать загрузку примера.
2. Дождаться перехода.
3. Открыть сводку.
4. Открыть отчёт.

Если нули остались, проверить, что демо записывает данные в активное состояние, а не только в локальную копию.

## Сортировка не меняет порядок

Если в категории одна запись, визуально сортировка может быть незаметной. Проверить:

- сортировку категорий;
- сортировку позиций внутри категории;
- каталог типовых позиций.

## Кнопка домой ведёт не на главную

Проверить настройку стартового экрана. Стартовый экран должен применяться только при запуске, а кнопка домой должна вести на `/`.

## Ошибка headerTitle undefined

Проверить `app/it-cost/_layout.tsx`: заголовок должен безопасно брать route name и иметь fallback.

## Дубли вкладок

Запустить:

```bash
npm run check:duplicates
```

Во вкладках должны быть только:

- Меню ИТ;
- Отчёт.

## Не открывается маршрут

Запустить:

```bash
npm run check:router
npm run check:functionality
```
