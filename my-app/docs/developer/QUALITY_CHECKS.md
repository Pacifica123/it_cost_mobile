# Проверки качества

## Полная проверка

```bash
npm run check
```

Эта команда запускает:

1. Очистку старых вкладок.
2. Генерацию вкладок.
3. Проверку роутера.
4. Проверку дублей.
5. Проверку функциональности.
6. Проверку Меню ИТ.
7. Логические тесты.

## Отдельные проверки

```bash
npm run cleanup:stale-tabs
npm run gen:tabs
npm run check:router
npm run check:duplicates
npm run check:functionality
npm run check:menu-it
npm run test:logic
```

## Когда запускать

- после добавления экрана;
- после переименования маршрута;
- после изменения меню;
- после изменения хранилища;
- перед сборкой APK;
- перед публикацией релиза.

## Проверка вручную

Перед релизом открыть приложение и проверить:

- светлую тему;
- тёмную тему;
- компактный/обычный/крупный режим;
- загрузку примера;
- Меню ИТ;
- Проект;
- Расчёты;
- Аналитику;
- Отчёт;
- Настройки;
- Проверку обновлений;
- Импорт CSV;
- Экспорт отчёта.

## Минимальный smoke-test

1. `npm run fresh`
2. Открыть приложение.
3. Загрузить пример.
4. Проверить, что сводка и отчёт не по нулям.
5. Переключить тёмную тему.
6. Переключить размер интерфейса.
7. Проверить, что кнопка домой ведёт на главную.
